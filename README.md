# Jarvis-AI-Assistant 

A friendly, local AI assistant designed to run privacy-first and entirely on your own systems. Jarvis bridges the gap between powerful language models and your local machine, featuring a clean frontend interface and a robust backend.

## Features

- **100% Local & Private:** No data leaves your machine. Your conversations and data remain entirely yours.
- **Modern Web Interface:** Clean and intuitive frontend built for seamless user interaction.
- **Interruptible AI Responses:** Stop the AI mid-generation instantly using the `Esc` key or a dedicated on-screen button.
- **Asynchronous Architecture:** Fast, non-blocking communication between the frontend and backend.
